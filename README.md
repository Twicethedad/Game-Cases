# Game-Cases
Real console cases around your Steam library artwork.
Features

	•	Nine cases included: Steam, PS2, PS3, PS4, Xbox 360, GameCube, Wii, Wii U and Switch.
	•	Driven by your Steam collections. Add a game to a collection and it gets that case, usually
within 30 seconds. No separate library to maintain.
	•	Matched set. Every case has the same outline, edge thickness, corner radius and banner height,
so a shelf of mixed consoles looks consistent.
	•	Nothing is modified. Your grid artwork, your collections and Steam's own pages are untouched.
	•	Add your own cases. Drop a 600x900 PNG into a folder and it appears in the settings.
	•	Light. Cases are drawn with a single stylesheet; the plugin does no work while you are idle.

Install

	1.	Install Decky Loader if you haven't already.
	2.	Download game-cases.zip from Releases.
	3.	On the device: Decky settings > General > turn on Developer mode.
	4.	Decky settings > Developer > Install plugin from ZIP > choose the zip.
	5.	Restart Steam (power menu > Restart Steam), or reboot.

Setting it up

Open Quick Access (the "..." button) > plug icon > Game Cases.

Collections named PS2, PS3, PS4, Xbox 360, GameCube, Wii, Wii U, Switch and Steam are matched
to their case automatically. Every collection also has a dropdown if you want a different case, or
none at all.
Setting	What it does
Show cases	Turns every case on or off instantly.
Art drop	How far the cover slides down behind the case's banner. Default 50%: a little of the top hides behind the banner, a little is trimmed off the bottom.
Steam case for other Steam games	Puts the Steam case on Steam games that aren't in a cased collection. Emulators and apps never get it unless you choose it for them.
Original case headers	Off by default, so all cases share one banner height and matching logo sizes. On uses each console's original banner.
Check this screen	Troubleshooting: reports what the plugin can see on the current screen. Useful when reporting a problem.
